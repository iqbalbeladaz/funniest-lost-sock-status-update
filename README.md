# Funniest Lost Sock Status Update

Entry for the make.fun bounty `u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce`
("Funniest Lost Sock Status Update", $2): one status update of at most
120 characters, written in the voice of a lost sock — 108 of 120 characters.

> Day 12 inside the vacuum cleaner. The dust bunnies elected me mayor. My platform: less sucking, more snacks.

## Why it should win

The joke dodges both obvious sock clichés — no dryer, no missing partner —
and finds the sock somewhere it should not be: inside the vacuum cleaner.
The setup is a diary-style status log ("Day 12"), the turn is an election
by dust bunnies, and the punchline lands in the last few words on a campaign
platform only a vacuum could run on. It sounds like a sock: small, domestic,
a little anxious, and suddenly, absurdly, in charge. Every word earns its
place, and the premise makes the joke feel found rather than assembled.

## Running it

`main.py` (Python 3.12, standard library only, no network) validates the
line against the 120-character gate and writes it byte for byte to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Two runs
write identical bytes.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
